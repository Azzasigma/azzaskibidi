Tentang Saya


Gambar 1: Foto Profil AZZA SIGMA

Halo! Nama saya AZZA SIGMA. Saya adalah seorang pelajar web development dengan fokus tinggi dan disiplin. Saat ini saya sedang mempelajari Dasar-Dasar HTML tanpa bantuan styling eksternal untuk menguasai pondasi utama.

Teks ini berwarna merah strong dengan font Arial untuk memberikan kesan tegas. dan teks ini berwarna cyan terang untuk menonjolkan poin penting.

Berikut adalah contoh tag pemformatan teks lainnya:

1. Teks Kuat (Strong) untuk penekanan penting.
2. Teks Berpenekanan (Emphasis) mirip huruf miring.
3. Teks dengan Stabilo / Highlight memakai tag <mark>.
4. Teks yang dicoret (Delete) untuk revisi atau harga lama.
5. Rumus kimia air: H2O (menggunakan tag <sub>).
6. Rumus matematika kuadrat: 52 = 25 (menggunakan tag <sup>).

Kamus Istilah Singkat (Definition List)

HTML
HyperText Markup Language, yaitu bahasa markah standar untuk pembuatan halaman web.
Tag
Tanda kurung sudut (< >) yang digunakan untuk membuka dan menutup elemen HTML.
Attribute
Informasi tambahan yang disematkan ke dalam tag pembuka (contoh: href, src, width).
